# 📊 Образовательный сайт по теории вероятностей и математической статистике

Учебный проект — полноценный многостраничный веб-сайт для изучения теории вероятностей и математической статистики. Сайт работает на локальном сервере (localhost) и предназначен для демонстрации преподавателю и самостоятельного изучения студентами.

---

## 📌 О проекте

**Тип проекта:** Полноценный многостраничный веб-сайт (клиент-серверная архитектура)

**Технологический стек:**
- **Бэкенд:** ASP.NET Core (C#), Razor Pages
- **Фронтенд:** HTML5, CSS3, JavaScript
- **Визуализация:** Chart.js
- **Запуск:** локальный сервер через Visual Studio

**Адаптивность:** Полная адаптивность под ПК, планшеты и смартфоны (responsive design)

---

## 🎯 Цель проекта

Создать интерактивный образовательный сайт, который преподаватель может использовать как наглядное пособие на занятиях (демонстрация с локального компьютера), а студенты — как справочник и тренажёр для самостоятельного изучения теории вероятностей и математической статистики.

---

## 👥 Целевая аудитория

- **Преподаватель** — использует сайт на занятиях для демонстрации теории и интерактивных модулей.
- **Студенты** — изучают теорию, пользуются калькуляторами и визуализациями, проходят тесты для самопроверки.

> Регистрация, личные кабинеты и разграничение ролей не предусмотрены, так как сайт работает на локальном хосте и предназначен для демонстрации и самостоятельного изучения.

---

## 🗺️ Структура сайта

- **Главная** — краткое описание портала, навигация, аннотация разделов.
- **Теория** — список тем с конспектами:
  - Классическое и статистическое определение вероятности
  - Формула Байеса
  - Математическое ожидание и дисперсия
  - Нормальное распределение
- **Интерактивные модули** — визуализации и калькуляторы.
- **Тесты для самопроверки** — набор вопросов с автоматической проверкой и выводом результата.
- **О сайте** — информация о проекте и авторе.

---

## 🧩 Интерактивные модули

1. **Модуль «Бросок кубика/монеты»** — кнопка «Бросить», счётчик выпадений, сравнение эмпирической частоты с теоретической вероятностью, график распределения.
2. **Модуль «Нормальное распределение»** — слайдеры для изменения математического ожидания и стандартного отклонения, график кривой Гаусса перестраивается в реальном времени.
3. **Модуль «Калькулятор вероятностей»** — ввод данных, расчёт вероятности события, комбинаторные формулы.
4. **Модуль «Описательная статистика»** — ввод набора чисел, расчёт среднего, медианы, моды, дисперсии, построение гистограммы.

---

## ⚙️ Функциональные требования

### Навигация и контент
- Единое меню на всех страницах.
- Адаптивное мобильное меню (гамбургер).
- Страницы теории с формулами и пояснениями.

### Интерактивность
- Все модули работают без перезагрузки страницы (JavaScript).
- Графики строятся в реальном времени (Chart.js).
- Валидация ввода в калькуляторах.

### Тесты для самопроверки
- Список тестов по темам.
- Прохождение теста: выбор ответов, подсчёт баллов, вывод результата.
- Результат не сохраняется в базе (показывается пользователю сразу).

### Адаптивность
- Корректное отображение на экранах от 320 px до 1920 px.
- Мобильное меню, гибкая сетка, читаемые графики.
